## **Prompt for Gamma**

> **Title:** Programmation procédurale – Exemple d’un blog PHP sans POO
>
> **Goal:** Create a clear 10-slide presentation explaining the *programmation procédurale* approach in PHP, based on the example of a simple blog structure (without object-oriented programming).
>
> **Tone & Style:**
>
> * Professional but simple (educational style for IT students)
> * Use clean visuals and icons for clarity
> * Include short code snippets and diagrams when relevant
> * French language throughout
>
> **Slide Breakdown:**
>
> 1. **Titre** – *Programmation procédurale en PHP : comprendre la logique sans POO*
>    → Brève introduction + objectif de la présentation.
>
> 2. **Définition** – Qu’est-ce que la programmation procédurale ?
>    → Explication simple (code exécuté séquentiellement, fonctions, includes).
>
> 3. **Structure du projet** – Présentation de l’arborescence du dossier `blog-procedural/`.
>    → Schéma visuel ou arborescence du projet.
>
> 4. **Rôle des fichiers principaux**
>    → Description de `index.php`, `config.php`, `includes/`, `articles/`, `auteurs/`, etc.
>
> 5. **Flux logique** – Comment fonctionne le projet ?
>    → Étapes : index → list.php → show.php → add.php, etc.
>    → Flèche ou diagramme de flux.
>
> 6. **Exemple concret : `articles/add.php`**
>    → Extrait de code simplifié (formulaire d’ajout + insertion SQL).
>
> 7. **Avantages de l’approche procédurale**
>    → Rapidité, simplicité, facile à comprendre pour débutant.
>
> 8. **Limites et problèmes**
>    → Code dupliqué, sécurité faible, difficile à maintenir, pas de réutilisation.
>
> 9. **Comparaison avec la POO**
>    → Tableau simple “Procédurale vs POO” (temps, maintenance, évolutivité).
>
> 10. **Conclusion**
>     → Résumé : “Procédurale = rapide mais limitée” + recommandation d’évoluer vers la POO pour les projets à long terme.
>
> **Design tips for Gamma:**
>
> * Use icons for folders and files (for `articles/`, `includes/`, etc.)
> * Keep each slide focused on **1 idea max**
> * Add code blocks in monospaced style for clarity
