### Prompt to Generate the Presentation

> **Prompt:**
>
> Create a professional presentation in French titled **“Programmation procédurale en PHP vs POO”**.
> The goal is to explain the **logic of procedural programming** in PHP, show how it differs from **object-oriented programming (POO)**, and illustrate both with examples.
> Use a clean, modern layout with short text, clear bullet points, and syntax-highlighted PHP code blocks.
>
> **Structure:**
>
> 1. **Titre / Introduction**
>
>    * Programmation procédurale en PHP vs POO
>    * Objectif : comprendre la logique sans POO.
> 2. **Qu’est-ce que la programmation procédurale ?**
>
>    * Exécution linéaire du haut vers le bas.
>    * Utilisation de fonctions réutilisables.
>    * Organisation en fichiers (`includes`, `config.php`, etc.).
> 3. **Structure d’un projet “blog-procedural”**
>
>    * Dossiers : config.php, includes/, articles/, auteurs/.
>    * Courte description du rôle de chaque dossier.
> 4. **Rôle des fichiers principaux**
>
>    * index.php, config.php, includes/, articles/.
>    * Schéma du flux ou liste numérotée.
> 5. **Flux logique du projet**
>
>    * Étapes de navigation : index → list → show → add.
>    * Brève description des échanges de données.
> 6. **Exemple concret : `articles/add.php`**
>
>    * Inclure un extrait de code PHP pour insérer un article dans la base.
>    * Montrer la redirection après insertion.
> 7. **Avantages de l’approche procédurale**
>
>    * Rapidité, simplicité, idéal pour débutants et petits projets.
> 8. **Limites et problèmes**
>
>    * Code dupliqué, faible sécurité, maintenance difficile, peu réutilisable.
> 9. **Exemple POO : même fonctionnalité**
>
>    * Comparer une version procédurale et une version orientée objet pour la création et l’affichage d’un article.
>    * Mettre en évidence la modularité de la POO.
> 10. **Avantages de la POO**
>
>     * Réutilisabilité, maintenance, évolutivité, organisation.
> 11. **Limites de la POO**
>
>     * Complexité, performance, sur-ingénierie, temps de développement.
> 12. **Procédural vs POO : Tableau comparatif**
>
>     * Critères : rapidité, maintenance, évolutivité, réutilisation, taille du projet.
>     * Emoji ou symboles pour différencier.
> 13. **Conclusion**
>
>     * Procédural = simple et rapide pour débuter.
>     * POO = plus complexe mais plus puissante et évolutive.
>     * Transition naturelle vers frameworks modernes.
>

>
> * Thème clair et minimaliste, accents bleus.
